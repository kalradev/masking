# PDF Masking

Upload a PDF, redact sensitive data (email, phone, Aadhaar, PAN, SSN, credit card, IP, plus custom words), then preview and download the masked file.

## Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
